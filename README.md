# Mastercraft Sync

Desktop companion for [getmastercraft.com](https://getmastercraft.com): it keeps your Mastercraft ledger up to date from your PC.

Download the installer from **Releases**. Linking a PC needs a Mastercraft keeper account on getmastercraft.com.
